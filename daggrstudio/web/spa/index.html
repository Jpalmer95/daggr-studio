What this is

Daggr Studio turns a described goal into a running daggr workflow assembled from bricks that were verified — introspected against their live API, and for cheap modalities actually executed — before being offered to you.

  • Plan — a small model (default deepseek-ai/DeepSeek-V4.1-Flash) chooses bricks; it can only pick ids from the catalogue, and endpoints/params are filled in from the registry, never invented.
  • Validate — every endpoint and parameter is checked against the live Space. Findings carry stable codes.
  • Heal — deterministic repairs first (renamed parameters, dead Spaces, non-commercial swaps), then a model that may only emit ops from a closed vocabulary; rejected ops are reported with reasons.
  • Run — executed in-process with daggr's own executor, node by node, with repairs at run time (sleeping → retry, quota → your token, changed API → remap, deleted → fail over).
  • Share — published as a commit to a public dataset; leaderboard filtered by modality, industry, licence and compute.

No LLM writes the generated code: the spec is model-authored, app.py is deterministic codegen, so what you run here is what you download.
